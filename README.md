# VCS Coursework

This repository contains coursework developed for the **Version Control Systems (VCS)** module. It demonstrates web development using HTML, CSS, and JavaScript, alongside the use of Git and GitHub for version control.

## 📁 Repository Structure

```text
VCS-coursework/
│
├── index.html
│
├── sasson/
│   ├── homepage.html
│   ├── styles.css
│   ├── script.js
│   ├── actions.js
│   └── images/
│
└── sujen/
    └── index.html
```

## 🎮 Sasson – Game Store Website

The `sasson` folder contains a Steam-inspired game store website called **Nexus**.

### Features

* Featured games section
* Special offers
* Top-selling games
* Game search
* Light/dark theme switching
* Interactive game details
* Game tags and descriptions
* Game pricing
* Wishlist interface
* Responsive layout

### Technologies

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/sasson2347/VCS-coursework.git
```

Open the repository in **Visual Studio Code** or another code editor.

The projects can be opened directly in a web browser.

### Sasson's Website

```text
sasson/homepage.html
```

### Sujen's Website

```text
sujen/index.html
```

Alternatively, the projects can be run using the **Live Server** extension in Visual Studio Code.

## 🔧 Version Control
